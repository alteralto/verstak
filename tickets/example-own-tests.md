# У пакетов workspace и check нет своих тестов

`internal/workspace` и `internal/check` проверяются только через сквозные тесты `internal/job`.
Если сломается мелочь, например обрезка вывода в `check.Tail` или правило «нечего коммитить —
не ошибка» в `Workspace.Commit`, упадёт большой тест, и будет непонятно, где искать.

Нужно: модульные тесты для обоих пакетов. Для `check.Tail` — разрез по границе строки и
короткий вывод без изменений. Для `check.Run` — все команды выполняются даже после падения.
Для `Workspace` — `Commit` без изменений возвращает false без ошибки, а `Stat` видит новые
неотслеживаемые файлы.
